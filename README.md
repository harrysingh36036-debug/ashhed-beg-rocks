# Ashhad Beg Rocks

A personal website showcasing skills and projects.

## Overview

This is a simple, modern personal website built with HTML5, CSS3, and JavaScript. It features:

- Clean, responsive design
- Dark/light mode toggle
- Scroll-based animations
- Interactive hover effects
- Semantic HTML structure
- CSS custom properties for easy theming

## Sections

- **Header**: Site title and tagline
- **About**: Brief personal introduction
- **Skills**: Key competencies and technologies
- **Contact**: Contact information and call-to-action
- **Footer**: Copyright information

## Features

### Design
- Responsive layout that works on mobile and desktop
- Modern color scheme with blue accent colors
- Clean typography and spacing
- Subtle animations and transitions

### Interactivity
- Dark/light mode toggle (respects system preference)
- Smooth hover effects on skill cards
- Scroll-based fade-in animations
- Focus styles for keyboard navigation

### Technical
- HTML5 semantic elements
- CSS3 with Flexbox and Grid layouts
- Vanilla JavaScript (no dependencies)
- CSS custom properties for theming
- Optimized for performance and accessibility

## Development

### Viewing the Site
Simply open `index.html` in any modern web browser.

### Customization
- Modify `index.html` to update content
- Edit `styles.css` to change colors, fonts, or layout
- Update `script.js` to modify interactions or animations
- Change site title and description in HTML head meta tags

## Browser Support
- Modern browsers supporting CSS Grid, Flexbox, CSS Variables, and ES6 JavaScript
- Graceful degradation in older browsers (animations may not work but content remains accessible)
